# nucleos

<p align="center">
  <a href="README.md">English</a> ·
  <a href="README_CN.md">简体中文</a>
</p>

> 一个 agent OS 内核，以服务形式交付，带一个稳定的 ABI。

`nucleos` 是为**长生命周期 agent 会话**准备的运行时。内核拥有会话状态机、turn 循环的
syscall 面、预算强制、工具世代和那份持久的记录；**其余一切都在接口后面插进来**——
模型、工具、存储、隔离、策略。

两条承诺决定了其余一切的形状：

- **机制在内核，策略在外部。** 内核保证不变量，它从不决定什么被允许。
- **对话归调用方。** 内核记录它**实际发出**了什么、**实际做了**什么。它不保存你对话的
  第二份副本，因此不可能和你对这份对话产生分歧。

---

## 它不是什么

不是 agent 框架、不是 prompt 库、不是 RAG 管线、不是模型网关、不是集群编排器、
也不是沙箱。上面每一项，要么是内核调用的一个 seam，要么是调用方的事。

---

## 四条不变量

每一条都由一个类型或一个唯一入口强制，而不是靠约定。

|        | 不变量                           | 由谁强制                  | 破坏它的代价                     |
| ------ | -------------------------------- | ------------------------- | -------------------------------- |
| **I1** | 一个会话一个写者                 | 宿主持有的租约            | 日志的序号不再有意义             |
| **I2** | 每一次状态变更都是一条不可变事实 | 唯一追加路径 + 私有构造器 | 重放变成一个故事，而不是一个状态 |
| **I3** | 预算在花费**之前**检查           | 调模型之前先拿到许可      | 那不是预算，是账单               |
| **I4** | 内核记录**它自己**产生的         | 事实只能在内核里构造      | 记录变成一方的声称               |

## 形状

```text
                    contract          词汇：id、内容、工具、模型事实、
                       ▲              边界、授权、事实
        ┌──────────────┼──────────────┐
      ports          wire           （适配器插进 ports）
        ▲              ▲
      kernel ──────────┘
        ▲
   宿主：库形态，或走 ABI 的 daemon
```

| crate             | 是什么                                                                                                          |
| ----------------- | --------------------------------------------------------------------------------------------------------------- |
| `crates/contract` | 纯类型。零 I/O、零 async、零运行时。每个类型都 derive `Serialize` + `JsonSchema`，所以 ABI 文档从它生成。       |
| `crates/ports`    | 宿主必须实现的 seam：生成、嵌入、判定、工具、进程会话、策略、存储、时钟。没有实现——除了两个"答案而不是替身"的。 |
| `crates/kernel`   | _在建_。会话状态机、日志、门禁、轮次、重放。                                                                    |
| `crates/wire`     | _在建_。ABI：信封、路由表、错误映射、SSE 帧。                                                                   |

模块图是单向的，而且是被检查的：`contract ← ports ← kernel`，`wire` 与 `contract` 平级。
内核与 `wire` 互不命名。

## 怎么用

部署一次，然后每个会话跑一个循环：

```text
部署    声明模型、工具源、技能目录、策略
开会话  grant = { confine, tools, models, skills }   冻结，之后只能收窄
循环    inference → finish == tool_calls 就派发 → 拼回去 → 再来一轮
结束    close（可逆）· reopen · delete（墓碑）
```

**循环是调用方的**，这是刻意的：内核不认为一轮之后必须有下一轮。

三个退出条件都是调用方的：模型答完了、预算用完了、或者它已经拿到想要的答案。
三个条件里，内核只决定其中一个。

## 状态

`0.0.1`。很早，而且对此诚实。

|                 |                                               |
| --------------- | --------------------------------------------- |
| ✅ 已建并测试   | `contract`（90 个测试）、`ports`（23 个测试） |
| 🚧 在建         | `kernel`、`wire`                              |
| 📄 已设计未实现 | daemon、CLI、适配器、OpenAPI 文档             |

```bash
cargo test --workspace      # 113 个测试
cargo clippy --workspace --all-targets
make fmt-check              # rustfmt + prettier，一道闸管两边
```

ABI 版本与 crate 版本是两件事：一次内核升级可以继续说旧的 ABI，把两者混为一谈，
就是"我们升级了 daemon，然后 SDK 挂了"。
